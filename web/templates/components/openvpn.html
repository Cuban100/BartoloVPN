Windows Setup

1 Download OpenVPN Client

Download the official OpenVPN client for Windows:

Download OpenVPN for Windows

Choose either OpenVPN Connect (recommended for beginners) or OpenVPN GUI

2 Install OpenVPN
  1. Run the downloaded installer as Administrator
  2. Follow the installation wizard
  3. Leave all default options selected
  4. Restart your computer if prompted
3 Generate Client Configuration
  1. Click "Add Client" button above
  2. Enter a name for your device (e.g., "john-laptop")
  3. Select protocol (UDP recommended)
  4. Click "Add Client"
  5. Download the generated .ovpn file
4 Import Configuration
OpenVPN Connect:
  1. Open OpenVPN Connect app
  2. Click "+" → "File"
  3. Select your downloaded .ovpn file
  4. The profile will be imported automatically
OpenVPN GUI:
  1. Right-click OpenVPN GUI icon in system tray
  2. Select "Import" → "Import file"
  3. Choose your .ovpn file
  4. Right-click the tray icon → Select your profile → "Connect"
5 Connect to VPN
  1. Open your OpenVPN client
  2. Select your imported profile
  3. Click "Connect" or toggle the switch
  4. Wait for connection to establish (usually 5-10 seconds)
6 Verify Connection
Check Your IP Address Test for DNS Leaks

Your IP address should now show the VPN server location.

Windows Troubleshooting
Connection Failed
  • Right-click OpenVPN → "Run as Administrator"
  • Check Windows Firewall settings
  • Temporarily disable antivirus
  • Try TCP protocol instead of UDP
No Internet Access
  • Check if VPN is routing all traffic
  • Flush DNS cache: ipconfig /flushdns
  • Reset network: ipconfig /release && ipconfig /renew

macOS Setup

1 Download OpenVPN Client

Choose one of these options:

Tunnelblick (Free, Recommended) OpenVPN Connect
2 Install Client
Tunnelblick:
  1. Download and open the .dmg file
  2. Drag Tunnelblick to Applications folder
  3. Launch Tunnelblick (may require admin password)
  4. Allow system extensions if prompted
OpenVPN Connect:
  1. Download from Mac App Store or website
  2. Install and launch the application
3 Generate and Import Configuration
  1. Click "Add Client" button above
  2. Enter a name for your Mac (e.g., "johns-macbook")
  3. Download the .ovpn file
  4. Tunnelblick: Double-click the .ovpn file
  5. OpenVPN Connect: Import via app interface
4 Connect to VPN
  1. Click Tunnelblick icon in menu bar
  2. Select your configuration
  3. Click "Connect"
  4. Enter admin password if prompted
5 Verify Connection
# Check public IP via Terminal
curl ifconfig.me

# Test DNS resolution
nslookup google.com

Linux Setup

1 Install OpenVPN
# Update package list
sudo apt update

# Install OpenVPN and dependencies
sudo apt install openvpn network-manager-openvpn-gnome

# For command-line only:
sudo apt install openvpn resolvconf
# CentOS/RHEL 8+
sudo dnf install epel-release
sudo dnf install openvpn NetworkManager-openvpn-gnome

# CentOS/RHEL 7
sudo yum install epel-release
sudo yum install openvpn NetworkManager-openvpn-gnome
# Install OpenVPN
sudo pacman -S openvpn networkmanager-openvpn

# Enable NetworkManager service
sudo systemctl enable NetworkManager
sudo systemctl start NetworkManager
# Install OpenVPN
sudo dnf install openvpn NetworkManager-openvpn-gnome

# Restart NetworkManager
sudo systemctl restart NetworkManager
2 Generate Configuration
  1. Click "Add Client" button above
  2. Enter a name for your Linux machine
  3. Download the .ovpn file
3 Connect via GUI
  1. Open Settings → Network
  2. Click "+" next to VPN
  3. Select "Import from file"
  4. Choose your .ovpn file
  5. Toggle the VPN connection on
4 Connect via Command Line
# Copy config to OpenVPN directory
sudo cp your-config.ovpn /etc/openvpn/client/

# Rename to .conf extension
sudo mv /etc/openvpn/client/your-config.ovpn /etc/openvpn/client/your-config.conf

# Start OpenVPN
sudo openvpn --config /etc/openvpn/client/your-config.conf

# Or start as service
sudo systemctl start openvpn-client@your-config
sudo systemctl enable openvpn-client@your-config
5 Verify Connection
# Check public IP
curl ifconfig.me

# Check VPN interface
ip addr show tun0

# Test DNS
nslookup google.com

# Check routing table
ip route show

iOS Setup

1 Install OpenVPN Connect

Download from the App Store:

OpenVPN Connect
2 Generate Configuration
  1. Click "Add Client" button above
  2. Enter a name for your iOS device
  3. Email the .ovpn file to yourself or use AirDrop
3 Import Configuration
  1. Open the email with .ovpn attachment on your iOS device
  2. Tap the .ovpn file attachment
  3. Choose "Copy to OpenVPN"
  4. OpenVPN Connect will open automatically
  5. Tap "Add" to import the profile
4 Connect to VPN
  1. Toggle the switch next to your profile
  2. Tap "Allow" when prompted for VPN configuration
  3. Use Face ID/Touch ID or enter passcode
  4. Wait for connection to establish
5 Verify Connection

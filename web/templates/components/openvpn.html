Remove All OpenVPN Clients

Warning: This action cannot be undone!

This will permanently remove all OpenVPN client configurations and revoke all certificates.

  • All client .ovpn configuration files will be deleted
  • All client certificates will be revoked and removed
  • All active connections will be terminated immediately
  • Clients will need new certificates if you add them again
  • This action affects ALL OpenVPN clients

Uninstall OpenVPN Service

DANGER: Complete Service Removal!

This will completely uninstall the OpenVPN service from your system.

  • Service will be stopped and removed
  • Complete PKI (Public Key Infrastructure) will be deleted
  • ALL certificates (CA, server, clients) will be lost
  • ALL client configurations will be deleted
  • Docker container will be removed
  • This action CANNOT be undone

CRITICAL: All OpenVPN clients will be permanently disconnected and will need completely new certificates to reconnect.

Windows Troubleshooting
Connection Failed
  • Verify server address is correct
  • Check Windows Firewall settings
  • Try connecting to a different network
  • Run Windows Network Troubleshooter
Authentication Failed
  • Double-check username and password
  • Ensure caps lock is off
  • Try recreating the VPN connection

Linux IKEv2 Setup

1 Install strongSwan
# Update package list
sudo apt update

# Install strongSwan and NetworkManager plugin
sudo apt install strongswan strongswan-swanctl
sudo apt install network-manager-strongswan

# For command-line only setup
sudo apt install strongswan-starter strongswan-charon
# CentOS/RHEL 8+
sudo dnf install strongswan NetworkManager-strongswan

# CentOS/RHEL 7
sudo yum install epel-release
sudo yum install strongswan NetworkManager-strongswan
# Install strongSwan
sudo pacman -S strongswan networkmanager-strongswan

# Enable and start strongSwan
sudo systemctl enable strongswan
sudo systemctl start strongswan
# Install strongSwan
sudo dnf install strongswan NetworkManager-strongswan

# Restart NetworkManager
sudo systemctl restart NetworkManager
2 Configure via GUI
  1. Open Settings → Network
  2. Click "+" next to VPN
  3. Select "IPsec/IKEv2 (strongswan)"
  4. Configure the connection:
YOUR_SERVER_IP
vpnuser
vpnpass-change-this
3 Command Line Configuration
# Create connection using NetworkManager CLI
nmcli connection add type vpn con-name "BartoloVPN-IKEv2" \\
ifname -- vpn.service-type org.freedesktop.NetworkManager.strongswan \\
vpn.data 'address=YOUR_SERVER_IP, encap=yes, ipcomp=no, method=eap, user=vpnuser'

# Set password (will prompt)
nmcli connection modify "BartoloVPN-IKEv2" vpn.secrets password=vpnpass-change-this

# Connect
nmcli connection up "BartoloVPN-IKEv2"
4 Verify Connection
# Check public IP
curl ifconfig.me

# Check VPN status
nmcli connection show --active | grep vpn

# Test DNS
nslookup google.com

# Check routing
ip route show

Remove All IKEv2 Users

Warning: This action cannot be undone!

This will permanently remove all IKEv2 user configurations and revoke access for all users.

  • All user credentials will be removed from strongSwan configuration
  • All active IKEv2 connections will be terminated immediately
  • Users will need to be reconfigured if you add them again
  • This action affects ALL IKEv2 users

Type "REMOVE ALL" to confirm this action:

Uninstall IKEv2 Service

DANGER: Complete Service Removal!

This will completely uninstall the IKEv2/IPSec VPN service from your system.

  • strongSwan IPSec service will be stopped and removed
  • ALL IKEv2 configurations will be deleted
  • ALL user credentials will be lost
  • PSK and certificates will be removed
  • Docker container will be removed
  • This action CANNOT be undone

CRITICAL: All IKEv2 clients will be permanently disconnected and will need completely new credentials to reconnect.

Type "UNINSTALL IKEV2" to confirm this action:

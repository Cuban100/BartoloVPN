Remove All IKEv2 Users

Warning: This action cannot be undone!

This will permanently remove all IKEv2 user configurations and revoke access for all users.

  • All user credentials will be removed from strongSwan configuration
  • All active IKEv2 connections will be terminated immediately
  • Users will need to be reconfigured if you add them again
  • This action affects ALL IKEv2 users

Type "REMOVE ALL" to confirm this action:

Uninstall IKEv2 Service

DANGER: Complete Service Removal!

This will completely uninstall the IKEv2/IPSec VPN service from your system.

  • strongSwan IPSec service will be stopped and removed
  • ALL IKEv2 configurations will be deleted
  • ALL user credentials will be lost
  • PSK and certificates will be removed
  • Docker container will be removed
  • This action CANNOT be undone

CRITICAL: All IKEv2 clients will be permanently disconnected and will need completely new credentials to reconnect.

Type "UNINSTALL IKEV2" to confirm this action:

Setup Instructions

Server Setup

1. Prerequisites
  • Ubuntu/Debian server with root access
  • Public IP address
  • Port 51820 (UDP) open in firewall
2. Install WireGuard
# Update package list
sudo apt update

# Install WireGuard
sudo apt install wireguard wireguard-tools

# Enable IP forwarding
echo 'net.ipv4.ip_forward=1' | sudo tee -a /etc/sysctl.conf
sudo sysctl -p
3. Generate Server Keys
# Create WireGuard directory
sudo mkdir -p /etc/wireguard
cd /etc/wireguard

# Generate private and public keys
sudo wg genkey | sudo tee server_private.key
sudo cat server_private.key | wg pubkey | sudo tee server_public.key
4. Configure Server

Create /etc/wireguard/wg0.conf with your server configuration:

[Interface]
PrivateKey = <SERVER_PRIVATE_KEY>
Address = 10.13.13.1/24
ListenPort = 51820
PostUp = iptables -A FORWARD -i %i -j ACCEPT; iptables -A FORWARD -o %i -j ACCEPT; iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
PostDown = iptables -D FORWARD -i %i -j ACCEPT; iptables -D FORWARD -o %i -j ACCEPT; iptables -t nat -D POSTROUTING -o eth0 -j MASQUERADE

Client Setup

1. Download WireGuard Client
Windows: Download from WireGuard.com
macOS: App Store or WireGuard.com
Android: Google Play Store
iOS: App Store
Linux: Package manager (wireguard-tools)
Windows Setup
  1. Download: Get WireGuard for Windows from the official website
  2. Install: Run the installer as Administrator
  3. Import Configuration:
    • Create a peer using "Add Peer" button above
    • Download the .conf file
    • In WireGuard app, click "Import tunnel(s) from file"
    • Select your downloaded .conf file
  4. Connect: Click "Activate" next to your tunnel
  5. Verify: Check your IP at whatismyipaddress.com
# Alternative: Import via command line (Run as Administrator)
cd "C:\Program Files\WireGuard"
wireguard.exe /installtunnelservice "C:\path\to\your\config.conf"
Linux Setup
Install WireGuard:
# Ubuntu/Debian
sudo apt update
sudo apt install wireguard wireguard-tools

# CentOS/RHEL/Fedora
sudo dnf install wireguard-tools
# or for older versions:
sudo yum install epel-release
sudo yum install wireguard-tools

# Arch Linux
sudo pacman -S wireguard-tools
Configure Client:
  1. Create a peer using "Add Peer" button above
  2. Download the .conf file
  3. Copy configuration to WireGuard directory:
# Copy config file (replace 'peer_name' with your actual peer name)
sudo cp /path/to/downloaded/peer_name.conf /etc/wireguard/

# Set proper permissions
sudo chmod 600 /etc/wireguard/peer_name.conf
sudo chown root:root /etc/wireguard/peer_name.conf
Connect and Manage:
# Start VPN connection
sudo wg-quick up peer_name

# Stop VPN connection
sudo wg-quick down peer_name

# Enable auto-start on boot
sudo systemctl enable wg-quick@peer_name

# Start service
sudo systemctl start wg-quick@peer_name

# Check status
sudo wg show
sudo systemctl status wg-quick@peer_name
Mobile Setup (Android/iOS)
  1. Install WireGuard app from your device's app store
  2. Create a peer using "Add Peer" button above
  3. Either:
    • QR Code: Use the QR code displayed after creating peer
    • File Import: Download .conf file and import into app
  4. Toggle the connection switch to connect
  5. Verify connection in app status
4. Verify Connection
# Check public IP (should show server IP)
curl ifconfig.me
# or visit: https://whatismyipaddress.com/

# Test DNS resolution
nslookup google.com

# Check WireGuard status (Linux/macOS)
sudo wg show

# Windows PowerShell (as Administrator)
Get-Service WireGuardTunnel*

Troubleshooting

Common Issues
Cannot Connect

Windows:

  • Run WireGuard as Administrator
  • Check Windows Firewall settings
  • Verify service is running: Get-Service WireGuardTunnel*
  • Check Event Viewer for WireGuard errors

Linux:

  • Verify server is running: sudo systemctl status wg-quick@wg0
  • Check firewall: sudo ufw status (Port 51820/UDP must be open)
  • Check network interface: ip addr show wg0
  • View logs: sudo journalctl -u wg-quick@peer_name -f

General:

  • Verify server public IP in client config
  • Check if port 51820/UDP is blocked by ISP
  • Try different server port in config
No Internet Access

Windows:

  • Check route table: route print
  • Verify DNS settings in WireGuard config
  • Disable IPv6 if causing issues
  • Try flushing DNS: ipconfig /flushdns

Linux:

  • Check IP forwarding: cat /proc/sys/net/ipv4/ip_forward should be 1
  • Verify NAT rules: sudo iptables -t nat -L
  • Check DNS settings: cat /etc/resolv.conf
  • Test with different DNS: dig @1.1.1.1 google.com
  • Check routing: ip route show

General:

  • Test with different DNS servers (1.1.1.1, 8.8.8.8, 9.9.9.9)
  • Verify AllowedIPs setting (should be 0.0.0.0/0 for full tunnel)
Poor Performance

Windows:

  • Check Task Manager for CPU/memory usage
  • Disable antivirus real-time scanning temporarily
  • Try different MTU values (1280, 1420)
  • Check network adapter settings

Linux:

  • Check server resources: htop, iotop, nethogs
  • Monitor bandwidth: iftop -i wg0
  • Test MTU: ping -M do -s 1472 google.com
  • Check kernel modules: lsmod | grep wireguard

General:

  • Try different server location/network
  • Test speed without VPN first
  • Consider server hardware limitations

Remove All WireGuard Peers

Warning: This action cannot be undone!

This will permanently remove all WireGuard peer configurations and disconnect all active clients.

  • All peer configuration files will be deleted
  • All active connections will be terminated immediately
  • Clients will need to be reconfigured if you add peers again
  • This action affects ALL WireGuard peers

Type "REMOVE ALL" to confirm this action:

Uninstall WireGuard Service

DANGER: Complete Service Removal!

This will completely uninstall the WireGuard VPN service from your system.

  • Service will be stopped and removed
  • ALL configuration files will be deleted
  • ALL peer data will be permanently lost
  • Docker container will be removed
  • This action CANNOT be undone

CRITICAL: All WireGuard clients will be permanently disconnected and unable to reconnect.

Type "UNINSTALL WIREGUARD" to confirm this action:
